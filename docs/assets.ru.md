# Ресурсы игры

[English version](assets.md)

Оставь `boot.config`, `RuntimeInitializeOnLoads.json` и `ScriptingAssemblies.json` в папке данных Windows-версии. Сборщик использует подходящие файлы Windows-игры и активированный Unity Editor, чтобы подготовить данные запуска для macOS.

В `manifests/assets.json` перечислены файлы для `Contents/Resources/Data` с относительными путями, размерами и SHA-256. Передай подходящую Windows-установку через `--game`. Скрипт копирует исходные файлы, адаптирует каталог и кэш Addressables, создаёт данные запуска и готовит 247 звуковых банков.

Если готового бандла Addressables нет, сборщик может получить его из соответствующего Windows-бандла. Для перевода шейдеров Direct3D в Metal он собирает из исходников закреплённые версии Wine vkd3d и Khronos SPIRV-Cross и сохраняет их в кэше. Некоторым бандлам также нужны вычислительные шейдеры, собранные из официальных исходников Unity PostProcessing. Для этого нужен активированный Unity Editor 2023.1.0f1 с Mac Build Support. Каждый из 83 результатов сверяется с той же контрольной суммой SHA-256, что и готовая копия.

Для отдельного шейдера копирования глубины сборщик использует готовый бандл, если он есть и совпадает по контрольной сумме. Иначе он компилирует исходник из проекта в активированном Unity Editor 2023.1.0f1 с Mac Build Support. Свой путь к редактору можно указать через `--unity-editor`.

Активированный редактор также предоставляет встроенные ресурсы Unity и генерирует потоки заставки и загрузочных текстур. Остальные файлы ресурсов запуска сборщик получает из временного проекта Unity, созданного из подходящих данных Windows-игры. Допустимые контрольные суммы указаны в манифесте.

## Повторное использование ресурсов

Обычная сборка готовит эти файлы автоматически. Если у тебя есть подходящая сборка для Mac, можешь извлечь проверенные ресурсы для повторного использования через `--private`. В `PORT` укажи существующий `.app`, а в `PRIVATE` — отдельную папку вне репозитория. Скрипт поместит файлы в `PRIVATE/assets/Contents/Resources/Data/`.

```bash
python3 scripts/build-assets.py --export-private "$PORT" --private "$PRIVATE"
```

Если нужно преобразовать исходные Windows-банки, `build.sh` скачивает закреплённый коммит wwiser в кэш и сверяет результаты преобразования с манифестом. Можно также использовать подготовленные банки или локальную копию конвертера. [Репозиторий wwiser](https://github.com/bnnm/wwiser)

1. Добавь `--include-banks` к команде извлечения. Она также скопирует 247 подготовленных `.bnk`. Храни извлечённые файлы игры локально.
2. Передай чистую копию wwiser на коммите `08e937b649bc7007c234bbd59e34a41d5eef3b38` через `--wwiser /путь/к/wwiser`. Сборщик также обнаруживает подходящую копию в `PRIVATE/wwiser`.

Для отдельной проверки подготовленной папки выполни команду ниже. [Основная инструкция по сборке](../README.ru.md#сборка)

```bash
python3 scripts/build-assets.py --game "$GAME" --private "$PRIVATE" --tools "$HOME/Library/Caches/Risk2Mac" --check
```
