# Ресурсы игры

[English version](assets.md)

Для генерации оставь `boot.config` и `RuntimeInitializeOnLoads.json` в папке данных Windows-версии. Подготовленные копии для macOS из старого комплекта тоже подходят при совпадении контрольных сумм.

В `manifests/assets.json` перечислены 2 503 файла для `Contents/Resources/Data` с относительными путями, размерами и SHA-256. Передай подходящую Windows-установку как `--game`. Скрипт копирует из неё 2 158 файлов, нормализует каталог Addressables и окончания строк кэша, генерирует два загрузочных файла Unity и готовит 247 звуковых банков. Ещё 94 файла требуются из локальных компонентов порта.

Среди этих файлов 83 изменённых бандла Addressables, бандл копирования глубины для Metal и 10 загрузочных файлов или ресурсов восстановленного Unity Player. При переносе шейдеров байткод Direct3D был преобразован через SPIR-V в Metal Shading Language. В бандлах восстановлены варианты и привязки Unity и применены исправления глубины, облаков и постобработки. Текущий сборщик проверяет уже подготовленные бандлы. Восстановление этих бандлов и остальных данных запуска Unity пока выполняется отдельно.

Размести каждый файл `kind: private` в `PRIVATE/assets/Contents/Resources/Data/` по пути из манифеста. Если есть подходящий локальный порт, извлеки эти 94 файла командой ниже.

```bash
python3 scripts/build-assets.py --export-private "$PORT" --private "$PRIVATE"
```

Если готовых банков и локальной копии инструмента нет, `build.sh` скачивает закреплённый коммит [wwiser](https://github.com/bnnm/wwiser) из репозитория автора в кэш. Скрипт преобразует исходные Windows-банки и сверяет результат с манифестом. Для офлайн-сборки подойдёт любой вариант ниже.

1. Добавь `--include-banks` к команде извлечения. Она также скопирует 247 подготовленных `.bnk`. Всего получится 341 файл ресурсов. Храни их в локальной папке.
2. Передай чистую копию wwiser на коммите `08e937b649bc7007c234bbd59e34a41d5eef3b38` через `--wwiser /путь/к/wwiser`. Сборщик также обнаруживает подходящую копию в `PRIVATE/wwiser`.

Проверка перед сборкой.

```bash
python3 scripts/build-assets.py --game "$GAME" --private "$PRIVATE" --tools "$HOME/Library/Caches/Risk2Mac" --check
```
