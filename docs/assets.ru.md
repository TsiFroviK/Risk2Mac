# Ресурсы игры

[English version](assets.md)

В `manifests/assets.json` перечислены 2 503 файла для `Contents/Resources/Data` с относительными путями, размерами и SHA-256. Передай подходящую Windows-установку как `--game`. Скрипт копирует из неё 2 158 файлов, нормализует каталог Addressables и окончания строк кэша, а также готовит 247 звуковых банков. Ещё 96 файлов требуются из локальных компонентов порта.

Среди этих файлов 83 изменённых бандла Addressables, бандл копирования глубины для Metal и 12 загрузочных файлов или ресурсов восстановленного Unity Player. При переносе шейдеров байткод Direct3D был преобразован через SPIR-V в Metal Shading Language. В бандлах восстановлены варианты и привязки Unity и применены исправления глубины, облаков и постобработки. Текущий сборщик проверяет уже подготовленные бандлы. Полное восстановление этих бандлов и данных запуска Unity пока остаётся отдельным процессом.

Размести каждый файл `kind: private` в `PRIVATE/assets/Contents/Resources/Data/` по пути из манифеста. Если есть подходящий локальный порт, извлеки эти 96 файлов командой ниже.

```bash
python3 scripts/build-assets.py --export-private "$PORT" --private "$PRIVATE"
```

Для звуковых банков есть два варианта.

1. Добавь `--include-banks` к команде извлечения. Она также скопирует 247 подготовленных `.bnk`. Всего получится 343 файла ресурсов. Храни их в локальной папке.
2. Передай собственную копию [wwiser](https://github.com/bnnm/wwiser) на коммите `08e937b649bc7007c234bbd59e34a41d5eef3b38` через `--wwiser /путь/к/wwiser`. Скрипт преобразует звуковые банки из Windows-установки и сверит результат с манифестом. Файлы wwiser в репозиторий не входят. Подходящая копия в `PRIVATE/wwiser` также обнаруживается автоматически.

Проверка перед сборкой.

```bash
python3 scripts/build-assets.py --game "$GAME" --private "$PRIVATE" --check
```
